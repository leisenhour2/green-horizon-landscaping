# Green Horizon Landscaping
Fictional landscaping company website created as a front-end portfolio project using HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Responsive Design

## Features

- Responsive layout
- Hero banner
- Services section
- Image gallery
- Customer testimonials
- Contact form
- Smooth scrolling
- Back-to-top button

## Future Improvements
- Gallery lightbox
- Dark mode
- Form submission backend
